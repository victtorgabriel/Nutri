# Conversão do NutriAcesso

Objetivo: abrir o site diretamente em index.html, com HTML, CSS e JavaScript nativos.

1. Preservar as sete seções, logo, cores, dados dos oito serviços e quatro resumos de artigos do projeto original.
2. Criar styles.css para layout responsivo, tipografia, cartões e estados acessíveis.
3. Criar data.js para os dados e app.js para busca sem acentos, filtros combinados, menu móvel e contato por e-mail.
4. Verificar busca, filtros, estado vazio, navegação, formulário e layout no navegador quando disponível. Validar sintaxe do JavaScript.

Não existe backend no original. O contato abrirá um rascunho no aplicativo de e-mail, sem afirmar envio. Os dados existentes são exemplos antigos e precisam de revisão antes da publicação. Após a organização, o site está em frontend/ e as configurações antigas em legacy/. O código original permanece em src/ porque o Windows bloqueou a movimentação da pasta. A pasta backend/ está reservada para implementação futura. O index.html da raiz encaminha ao frontend.
